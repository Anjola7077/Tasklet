Tasklet

A simple, modern task manager for Android.

Tasklet is a lightweight task management application built with C# and .NET MAUI. It helps users organize their tasks, keep track of deadlines, and stay productive through a clean interface and local notifications.

Installation

1. Open the download link above.
2. Download the APK file to your Android device.
3. Open the downloaded APK.
4. If prompted, allow your browser or file manager to install apps from that source.
5. Complete the installation and launch Tasklet.

«Note: Android may display a security warning when installing an APK outside the Google Play Store. Only install APKs from sources you trust.»

Features

- Task Management: Create and manage your tasks.
- Task Organization: Filter tasks by All, Today, Upcoming, and Done.
- Reminders: Schedule local notifications to help you remember important tasks.
- Local Storage: Store task data on your device.
- Clean Interface: A modern, minimalist design focused on usability.
- Android Support: Built with .NET MAUI for Android.

Feature availability may vary depending on the current build.

Built With

- C# – Application logic
- .NET MAUI – Cross-platform application framework
- XAML – User interface
- Plugin.LocalNotification – Local notifications
- CommunityToolkit.Mvvm – MVVM utilities
- JSON – Local task data storage

Project Structure

The project includes the following key components:

- "MainPage.xaml" – Main application interface
- "MainPage.xaml.cs" – Main page logic
- "TaskEditorPage.xaml" – Task editing interface
- "App.xaml" – Application resources
- "AppShell.xaml" – Application navigation
- "Resources/" – Application icons, images, fonts, and styles
- "Platforms/Android/" – Android-specific configuration and functionality

Exact files and folders may vary with the current project version.
